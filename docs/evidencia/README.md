# Evidencia

- [flujo/](flujo/): salida de cada etapa del flujo de Prefect.
- [flujo-completo/](flujo-completo/): el flujo con entrenamiento real, desde cero.
- [flujo-rechazo-v6/](flujo-rechazo-v6/): el flujo con un candidato que no pasa los criterios (la v6).
- [modelos/](modelos/): mediciones de deslizadores, semillas y modelos históricos.
- Los resultados oficiales están en `metrics/`, el historial de promociones y rollback en `manifests/historial.json` y cada veredicto de selección en `manifests/decisiones.json`.
