PiezaQué garantiza

AmbienteVersión (0.1 → 0.4) y huella en cada manifiesto; los modelos viejos corren con su versión

PrefectValida, prueba, entrena, selecciona, publica y comprueba la versión que sirve la API

Registrar un candidato no lo promueve: promover exige pasar los criterios fijados antes.

Recuperar un modelo viejo

1. Leer su manifiesto: etiqueta, SHA-256 y ambiente.

2. Traer sus pesos: git checkout <etiqueta> y dvc checkout

3. Evaluarlo con su ambiente compatible. La v4 corre con un adaptador validado.

Rollback probado

v5 → v4 → v5, comprobando la versión que sirve la API.
