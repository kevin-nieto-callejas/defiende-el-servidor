  • Abrir el catálogo y leer versión, ambiente, commit y SHA-256
  • Comparar la v1 con la recomendada (v6-s1), seco y lluvia
  • Pista Puerto: la v5-s1 se sale y la v6-s1 completa

Tocar la pantalla una vez para activar el sonido. La API corre en la misma URL, como función de Vercel: el catálogo evalúa en vivo y los deslizadores corren experimentos nuevos. Cada resultado dice motor (numpy para PPO), ambiente y commit. Si la API no responde, la web entra en replay y lo dice. Antes de mover todos los deslizadores al extremo a la vez, avisar que combinados el modelo falla. Para el Puerto: autonomous-rally.vercel.app/?pista=puerto, correr ppo-modelo-v5-s1 (en seco se sale a los 28.4 s) y después ppo-modelo-v6-pistas-s1. Moto: ?vehiculo=moto. La cámara TV (tecla 2) deja oír el carro pasar con Doppler. La Sierra no está en el selector: es la prueba reservada.
