autonomous-rally.vercel.app

  • Abrir el catálogo y leer versión, ambiente, commit y SHA-256
  • Cargar un modelo histórico y ver que se marca como tal
  • Comparar la v1 con la versión recomendada, seco y lluvia
La API corre en la misma URL, como función de Vercel: el catálogo evalúa en vivo y los deslizadores corren experimentos nuevos. Cada resultado dice motor (numpy para PPO), ambiente y commit. Si la API no responde, la web entra en replay y lo dice en la nota del panel. Antes de mover todos los deslizadores al extremo a la vez, avisar que combinados el modelo falla.
